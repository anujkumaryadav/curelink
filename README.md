# 🎤 Spell Bee Voice Bot

A voice-powered spelling bee game built with TypeScript, Next.js, and browser Web Speech API. Practice your spelling skills with an AI-powered bot that presents words and validates your spelling in real-time!

## ✨ Features

- 🗣️ **Voice Recognition** - Spell words using your voice
- 🤖 **AI Bot** - Powered by Google Gemini
- 📊 **Score Tracking** - Real-time scoring and statistics
- 💬 **Real-time Feedback** - Instant validation and encouragement
- 🌐 **Browser-based** - No external services required for speech recognition
